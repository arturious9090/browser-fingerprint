# Руководство пользователя и владельца

[Оглавление](README.md)

## Страница посетителя

1. Откройте главную страницу и нажмите «Запустить сбор».
2. Выберите «Только в браузере» либо «Согласен, отправить». «Отмена» и Escape закрывают окно без запуска основного сбора.
3. Дождитесь состояния завершения. Количество и доступность проверок зависят от браузера, устройства и настроек приватности.

В режиме «Только в браузере» собранный отчёт остаётся в памяти вкладки и не записывается в SQLite. Страница всё равно загружает ресурсы и выполняет сетевые измерения `/api/ping`: сервер наблюдает обычные соединения. Локальный режим не означает полное отсутствие HTTP-запросов.

При согласии отчёт сохраняется у владельца. Посетитель видит подтверждение отправки; таблиц значений, ID записи, скачивания JSON и удаления отчёта на публичной странице нет. Это ограничение интерфейса и серверного API. Сам браузер технически имеет доступ к сформированным в нём данным; они не являются секретом от владельца устройства.

После локального сбора можно нажать «Отправить данные»: потребуется отдельное согласие. Обновление или закрытие вкладки теряет её несохранённый отчёт. Повторная отправка создаёт новую запись, а не обновляет предыдущую.

Если отправка не подтверждена, интерфейс предложит повторить её с новым согласием. При потере ответа сервер мог уже сохранить первую попытку, поэтому повтор может создать ещё одну запись.

## Дополнительные проверки

Откройте раздел «Дополнительные проверки с разрешением» и запустите нужный пункт:

| Проверка | Что может вернуться |
| --- | --- |
| WebRTC / ICE | Локальные ICE-кандидаты или mDNS-имена без внешних STUN/TURN; публичный IP этим тестом не определяется |
| Геолокация | Разрешённые браузером координаты, точность и связанные значения |
| Локальные шрифты | Полный список, если поддерживается Local Font Access |
| Раскладка клавиатуры | Keyboard Layout Map; введённый текст и сами нажатые клавиши не записываются |
| Подключённые экраны | Размеры, расположение и названия экранов, раскрываемые Window Management API |
| Ранее разрешённые устройства | Сведения об уже разрешённых USB/HID/Bluetooth/Serial-устройствах |
| Камера и микрофон | Названия, настройки и возможности треков; треки останавливаются, кадры и звук не сохраняются |

Системный запрос разрешения появляется, когда этого требует браузер. Запуск дополнительных проверок сам по себе ничего не отправляет владельцу. Для сохранения текущих результатов снова нажмите «Отправить данные» и подтвердите согласие. Новый основной сбор заменяет прежний отчёт и сбрасывает результаты предыдущих дополнительных проверок.

Агрегаты событий вкладки считаются с открытия страницы: количество движений, кликов, keydown, прокруток и изменений фокуса/видимости. Текст, сами клавиши и сырые траектории не сохраняются. Агрегаты добавляются в отчёт при отправке.

## Вход владельца

Локально откройте `/admin` на том же адресе, что и сайт. Ключ находится в `.data/owner-key.txt` рядом с базой. Если используется `DATABASE_PATH`, файл ключа создаётся в каталоге этой базы.

В production откройте SSH-туннель по [инструкции VPS](../DEPLOYMENT.md), затем перейдите на `http://127.0.0.1:8080/admin`. На публичном домене кабинет недоступен. Docker-ключ хранится в `/data/owner-key.txt` внутри app-контейнера. Публичной регистрации и других аккаунтов нет.

После входа доступны:

- Список отправленных отчётов и поиск по IP, User-Agent, хешу профиля или ID.
- Пагинация по 25 записей и кнопка обновления списка.
- Полный отчёт с категориями, поиском и краткой справкой по параметрам.
- Отдельные вкладки клиентских параметров, серверного наблюдения и признаков автоматизации.
- Текст, версия и время согласия; скачивание JSON выбранной записи.

Сессия истекает через 30 минут бездействия или максимум через 8 часов. «Выйти» отзывает её на сервере. Для смены ключа и отзыва всех сессий используйте `npm run admin:rotate` локально или соответствующую Docker-команду из инструкции VPS. Ротация не удаляет отчёты.

Кнопки удаления отдельного отчёта в кабинете нет. По текущей реализации удаление старых записей выполняется политикой хранения; порядок настройки описан в [конфигурации](CONFIGURATION.md).

## Как читать результаты

IP — адрес, наблюдаемый сервером либо Caddy; VPN, прокси и NAT могут скрывать адрес устройства. Название устройства и платформы сообщаются браузером и могут быть сокращены или изменены.

`unsupported`, `blocked`, `timeout` и отсутствие значения не являются признаками бота сами по себе. `webdriver` сообщает об объявленной автоматизации, но не о вредоносности. Хеш профиля меняется при обновлениях, смене настроек или защитной рандомизации и не гарантирует уникальность.

Подробные значения статусов и полей приведены в [модели данных](DATA-MODEL.md). Если сбор, вход или отправка не работают, используйте [диагностику проблем](TROUBLESHOOTING.md).

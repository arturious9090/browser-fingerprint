# Документация Fingerprint Lab

[Главная проекта](../README.md)

Документация описывает текущую реализацию JavaScript + Node.js + SQLite. Примеры ключей, токенов и IP в справочниках — демонстрационные. Реальные данные из рабочей базы в эти файлы не включаются.

## С чего начать

- Посетителю или владельцу: [руководство пользователя](USER-GUIDE.md).
- Для публикации на VPS: [инструкция запуска и эксплуатации](../DEPLOYMENT.md), затем [справочник настроек](CONFIGURATION.md).
- Разработчику: [архитектура](ARCHITECTURE.md), [разработка](DEVELOPMENT.md), [API](API.md), [модель данных](DATA-MODEL.md).
- При ошибках: [диагностика проблем](TROUBLESHOOTING.md).

## Режимы работы

| Свойство | Локальная разработка | Production в поставляемом Compose |
| --- | --- | --- |
| Публичный адрес | `http://127.0.0.1:4173` по умолчанию | `https://DOMAIN` |
| Вход владельца | `/admin` на локальном адресе | Только SSH-туннель → `http://127.0.0.1:8080/admin` |
| Соединение с Node | Loopback TCP | Unix socket, контейнер без сети |
| Данные | `.data/` относительно рабочего каталога | Docker volume `app_data`, каталог `/data` |
| Автоочистка | Отключена по умолчанию | Старше 30 дней по умолчанию |
| Аудит безопасности | По умолчанию отключён | JSON в stdout, ограничение частоты и ротация Docker-журналов |

`/admin` и `/api/admin/*` на публичном production-домене возвращают 404 намеренно. Это не ошибка маршрутизации.

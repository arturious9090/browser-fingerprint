# Проверка 21 октября 2026: подготовка к интернету

- **52 теста прошли внутри итоговой Linux Docker-сборки**. Проверены production-ограничения, приватные маршруты, CSRF/Origin/Fetch Metadata, одноразовое согласие, сессии, ротация ключа, безопасные ошибки, квоты и ограничения SQLite.
- Отдельные регрессии подтверждают: медленные параллельные POST входа запускают только одну дорогую проверку; смена ключа во время проверки не выдаёт сессию по старому ключу. Создание сессии сверяет credential в SQLite-транзакции.
- Реальный предел страниц SQLite проверен записью больших тестовых отчётов: ответ 507 без потери уже сохранённых записей. Проверены ограничение количества записей и очистка по серверному времени.
- Итоговый Docker-образ прошёл интеграционную проверку через Caddy: TLS с проверяемым временным локальным CA, публичный `/admin` и административные API — 404; локальная точка управления требует ключ; вход/чтение/выход работают.
- Подставленные X-Real-IP/XFF/CF-заголовки не меняют наблюдаемый IP. У app-контейнера проверены network none, отсутствие PortBindings, UID node и read-only root.
- Подтверждены сохранение с согласием и приватность квитанции `{saved:true}`. Онлайн-backup создан отдельным контейнером с read-only рабочей БД и прочитан обратно; постоянно работающий app не получает backup-volume.
- Журнал проверен на отсутствие ключа, cookie, CSRF-токена и тестовой строки посетителя. Проверены ограничение частоты журнала, фиксированные события и подавление ошибок log sink.
- Проверены синтаксис Compose и Caddyfile. Базовые образы Node/Caddy зафиксированы по проверенным registry digests. Контекст Docker, dist и архив исключают реальную БД, ключ и `.env`.
- Временные контейнеры, CA и тестовые volumes удалены. Реальная локальная база не использовалась для Docker-проверок. Обновлённый dev-сервер работает на loopback 4174, HTTP-заголовки проверены.
- Публичного развёртывания не выполнялось. DNS, настоящий сертификат ACME, сетевой экран и ёмкость конкретного VPS проверяются при запуске по DEPLOYMENT.md. Нагрузочный пентест и сканирование образов на CVE не выполнялись; эти проверки не выдаются за пройденные.

Источники и соответствие изменений рекомендациям OWASP/Node/Docker/Caddy: SECURITY-PRACTICES.md.

# История: проверка 19 октября 2026

## Текущая версия: отчёты доступны только владельцу

- Все **32 автотеста прошли**. Публичные GET/DELETE/POST по ID отчёта возвращают 404, в том числе со старым заголовком удаления. Проверяется сохранность записи после этих запросов.
- После согласия сервер возвращает только `{saved:true}`: без ID отчёта, времени записи и ключа удаления. Список и детали по-прежнему требуют сессии владельца.
- Публичный `/api/connection` удалён; `/api/admin/connection` требует входа владельца. Сведения о соединении при отправке записываются сервером в закрытый отчёт.
- В браузере проверены выбор согласия и полный сбор без отправки: после завершения отображается только статус. Таблицы результатов, хеш, сигналы, экспорт JSON, ID записей и удаление отсутствуют на странице посетителя.
- На странице посетителя сохранены сведения о категориях собираемых данных и отдельные проверки с разрешением. Подробная справка параметров остаётся в админ-панели.
- Сервер проекта на порту 4174 перезапущен с новым кодом. Проверено, что старый публичный маршрут соединения возвращает 404. Существующая база сохранена.
- Сборка Node.js обновлена; секреты и SQLite не включены в архив исходников. Дизайн-скан изменённой страницы не нашёл замечаний. Снимок страницы: `/private/tmp/fingerprint-visitor-restricted.png`.

# Обновление: SQLite, согласие и кабинет владельца

- Финальный прогон: **31 тест прошёл**, включая реальный HTTP на временных localhost-портах и SQLite на диске.
- В реальном браузере «Только в браузере» завершило сбор 486 параметров; прямой запрос к SQLite подтвердил 0 сохранённых отчётов.
- После отдельного явного согласия сохранены все 486 параметров, текст/версия/серверное время согласия и отдельное наблюдение сервера при загрузке. В рабочей локальной базе оставлена одна проверочная запись.
- Проверены вход владельца без вывода ключа, список записей, детальный отчёт, общий текст справки WebDriver на клиенте и в кабинете, отдельный IP непосредственного соединения сервера.
- Автотесты покрывают закрытые list/detail/session API, отзыв сессии, 30-минутное бездействие и 8-часовой срок, CSRF/Origin, перебор ключа, Secure-cookie при HTTPS-origin, одноразовый токен согласия, запись без согласия, лимит тела запроса, SQL-поиск и приватный токен удаления.

- Готовая сборка `dist/` теперь является Node.js-приложением с SQLite, а не Worker. База и ключ владельца в неё не копируются. Внешней публикации не было.
- Порт 4173 занят существующим процессом; локальная проверка новой версии выполнена на 4174. Старый сервер необходимо перезапустить для загрузки обновлённого серверного кода.

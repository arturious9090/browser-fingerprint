# Fingerprint Lab

Сервис диагностики браузера и соединения с добровольной отправкой данных в SQLite и закрытым кабинетом владельца. Интерфейс на русском, тёмная техническая панель. Стек: JavaScript без фреймворка, Node.js 24.13+, встроенный `node:sqlite`. npm-зависимостей нет.

Посетитель выбирает сбор без отправки или согласие на сохранение. Значения, JSON-экспорт и сохранённые записи доступны только владельцу. Камера, микрофон, геолокация и другие дополнительные проверки запускаются отдельными действиями.

Отпечаток и признаки автоматизации служат диагностикой: они не доказывают личность, вредоносность или отсутствие бота.

## Быстрый локальный запуск

В каталоге исходников:

```sh
node --version
npm start
```

Откройте [сайт](http://127.0.0.1:4173/) и [кабинет владельца](http://127.0.0.1:4173/admin). При первом запуске создаются `.data/fingerprints.sqlite` и `.data/owner-key.txt`. Вставьте ключ из файла в форму входа; не публикуйте его. При занятом порте: `PORT=4174 npm start`.

Это режим разработки. Для публичного запуска используйте [инструкцию VPS](DEPLOYMENT.md): Docker + Caddy с HTTPS. В production админка закрыта на публичном домене; доступ — через SSH-туннель на `http://127.0.0.1:8080/admin` и ключ владельца.

## Основные команды

Из полного каталога исходников:

```sh
npm run dev
npm test
npm run build
npm run admin:rotate
```

`dev` запускает Node с наблюдением за файлами; `npm test` предварительно пересобирает `dist/`. Ротация ключа отзывает сессии, сохраняя отчёты. Инструкции по backup, безопасному хранению ключей и Docker-проверкам приведены в документации выше.

`dist/` — отдельный исполняемый Node-пакет. Внутри него доступны `npm start`, `npm run admin:rotate`, `npm run backup`. Реальная база, ключ и `.env` в пакет не копируются. Относительный путь к БД зависит от текущего рабочего каталога; для единой базы указывайте абсолютный `DATABASE_PATH`.

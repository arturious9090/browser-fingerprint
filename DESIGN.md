# Fingerprint Lab

Confirmed direction: dark technical panel with tables, Russian language. Operate mode: familiar sidebar navigation, searchable diagnostic rows, explicit statuses and a distinct automation report. The user's pinned direction takes precedence over visual-world exploration. Code-first app screen.

Deep ink ground, slightly blue surfaces, mint for measured data, amber for uncertainty, red only for actual warning signals. No numerical probability of humanity. Compact system sans for controls and prose; monospace only for field names and measured values. Thin separators, restrained rounding, no decorative graphics. A vertically aligned source/status column is the signature: every measurement exposes its provenance and availability. Mobile uses a horizontally scrollable category strip and stacked value rows.

Consent uses a native dialog with a focused choice before collection: local-only or explicit upload. Admin extends the same dark world and table component with list/search, detailed records, consent receipts and a separate server-observation tab. Help appears directly below each field, with expandable help for nested objects.

Visitor-page scope updated by the user: collection and explicit consent only, with status messages and permission-gated optional probes. Report values, navigation, hashes, signals, downloads, saved-record IDs and deletion controls are absent. The existing admin report interface remains the sole place to inspect stored data.

Проверка браузера

Диагностика устройства и соединения. Вы сами выбираете, отправлять ли собранные данные владельцу сайта.

Состояние проверки

Сбор ещё не запускался. Перед началом будет предложен выбор отправки.

Просмотр и скачивание отчётов доступны только владельцу сайта. На этой странице результаты и сохранённые записи не отображаются; удалить запись отсюда нельзя.

Какие данные собираются

Параметры браузера и ОС, экран, язык и часовой пояс, графические и аудиоотпечатки, доступные шрифты, поддерживаемые возможности API и характеристики соединения. При сохранении сервер добавляет собственные наблюдения, включая IP непосредственного соединения.

Без согласия на отправку собранные браузером данные остаются в памяти вкладки. Даже в этом режиме сервер получает обычные запросы страницы и теста связи, но отчёт в SQLite не сохраняется.

Дополнительные проверки с разрешением

Каждая проверка запускается отдельно. Она может запросить разрешение браузера. Результаты не отображаются и не отправляются автоматически: для отправки нужно нажать «Отправить данные» и дать согласие.

Как запустить диагностику?

Выберите, передавать ли диагностические данные владельцу сайта.

Камера, микрофон и геолокация проверяются только отдельными кнопками. Отмена и Escape не запускают сбор.
